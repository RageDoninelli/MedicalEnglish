V.I.V.A. MEDICAL ENGLISH LAB — V1

WHAT IS INCLUDED
- One functional Unit 1: Presenting Complaints
- 8 vocabulary flashcards with example sentences and browser text-to-speech
- A scripted patient interview with playback and transcript
- 5 listening comprehension questions
- Dialogue playback, individual lines, self-guided speaking practice
- 4 clinical communication challenges
- 10-question final assessment; pass at 70%
- Local progress storage and offline app-shell caching
- Units 2–12 shown as coming soon

DEPLOY TO GITHUB PAGES
1. Create a new GitHub repository (e.g. VIVAMedicalLab).
2. Upload the CONTENTS of this folder to the repository root (index.html, app.js, styles.css, etc.).
3. Settings > Pages > Deploy from a branch > main / root.
4. Open the published HTTPS URL on Android Chrome; use Add to Home screen / Install app.
5. To update later, replace the files and change the cache version in sw.js.

NOTES
- The app uses original English language learning material, not textbook reproductions.
- Browser speech synthesis is not a recorded audio track. Availability and offline behavior depend on the device's installed voice.
- No microphone, pronunciation grading, cloud sync or accounts are implemented.
- Progress is local to the current browser/device. Clearing data removes it.
- The colored VIVA text in the app is a PLACEHOLDER, not the official academy logo. Replace it with the original approved logo when provided.
- Clinical content is for language learning, not clinical decision support.
